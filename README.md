# Միջուկային բժշկության ազգային կենտրոն — կայք

Կենտրոնի նոր կայքը՝ հայերեն, անգլերեն և ռուսերեն։ Կայքը ստատիկ է, կառուցված է [Astro](https://astro.build)-ով և admin panel չունի. բովանդակությունը փոխվում է ֆայլերում, որից հետո կայքը նորից է build արվում։

> **Կարգավիճակ.** կայքը դեռ պատրաստ չէ հրապարակման։ Տե՛ս [Մնացած աշխատանքը](#մնացած-աշխատանքը)։

## Գործարկում

Պահանջվում է Node.js (մշակվել է 24 տարբերակով)։

```bash
npm install
npm run dev       # մշակման ռեժիմ՝ http://localhost:4321
npm run build     # վերջնական կայքը՝ dist/ պանակում
npm run preview   # dist/-ի նախադիտում
```

## Կառուցվածք

```
src/
  content/
    hy/, en/, ru/     բովանդակություն ըստ լեզվի (JSON)
    shared/           բոլոր լեզուների համար ընդհանուր տվյալներ
  i18n/               ինտերֆեյսի տեքստեր և լեզվի օգնական ֆունկցիաներ
  views/              էջերի իրական պարունակությունը
  pages/              URL-ներ. միայն միացնում են views-ը լեզվին
  components/         ձև, էջի վերնամաս, ֆիլտր
  layouts/Base.astro  header, footer, SEO
  styles/global.css   գույներ, տառատեսակներ և ամբողջ CSS-ը
  assets/media/       նկարներ, որոնք build-ի ժամանակ օպտիմալացվում են
public/
  img/                լոգոներ
  media/              տեսանյութեր
scripts/              մեկանգամյա օգնական սկրիպտներ
```

## Լեզուներ և հասցեներ

| Լեզու | Գլխավոր | Օրինակ |
|---|---|---|
| Հայերեն | `/` | `/pet` |
| Անգլերեն | `/en` | `/en/pet` |
| Ռուսերեն | `/ru` | `/ru/pet` |

Եթե `src/content/ru/`-ում աղյուսակի ֆայլ չկա, ռուսերեն էջը ցույց է տալիս անգլերեն տարբերակը։

## Բովանդակության փոփոխում

| Ինչ | Որտեղ |
|---|---|
| Գներ | `src/content/<լեզու>/prices.json` |
| Բժիշկներ | `src/content/<լեզու>/doctors.json` |
| Հարցեր | `src/content/<լեզու>/faqs.json` |
| Մամուլ | `src/content/<լեզու>/presses.json`, նոր հոդվածի slug-ը՝ `src/lib/press.ts` |
| PET և SPECT տեքստեր | `pets.json`, `spects.json` |
| Առավելություններ | `advantage_items.json` |
| Հասցե և աշխատանքային ժամեր | `contacts.json` |
| Կոճակներ, մենյու, վերնագրեր | `src/i18n/<լեզու>.json` |
| Հեռախոս և էլ. փոստ | `src/i18n/index.ts` |
| Տնօրենի տվյալներ | `src/i18n/<լեզու>.json` (`doctors.director.*`), լուսանկարը՝ `src/views/Doctors.astro` |

Գները փոխելիս թարմացրեք բոլոր լեզուների ֆայլերը. գումարները լեզուների միջև ավտոմատ չեն համաժամեցվում։

Փոփոխությունից հետո գործարկեք `npm run build` և թարմացրեք սերվերի ֆայլերը։

## Սկրիպտներ

| Հրաման | Ինչ է անում |
|---|---|
| `npm run import:content -- /ուղի/website-db.sql` | Հին բազայի dump-ից ստեղծում է `src/content/hy`, `en` և `shared` ֆայլերը |
| `node scripts/download-media.mjs` | Հին API սերվերից ներբեռնում է բովանդակության մեդիան |
| `node scripts/make-logo.mjs` | Կառուցում է լոգոները `../conference` նախագծի արտապատկերից |

**Զգուշացում.** `import:content`-ը վերագրում է ներմուծված ֆայլերը և կջնջի դրանցում ձեռքով արված փոփոխությունները։ Այն նախատեսված է միայն սկզբնական ներմուծման համար։

## Անվտանգություն

- Բազայի dump-ը երբեք մի ավելացրեք ռեպոյում. այն պարունակում է դիմումատուների անձնական և առողջական տվյալներ, ինչպես նաև հաշիվների տվյալներ։ `.gitignore`-ը բացառում է `*.sql` ֆայլերը։
- Ներմուծման սկրիպտը կարդում է միայն թույլատրված աղյուսակները (`ALLOWED` ցուցակը)։ Այդ ցուցակում մի ավելացրեք `emails`, `comments`, `users` կամ `personal_access_tokens` աղյուսակները։
- SMTP գաղտնաբառերը պետք է պահվեն միայն սերվերում՝ git-ից և web root-ից դուրս։
